# CIM Anonymizer
Обезличивание CIM-модели (IEC 61970/61968, RDF XML) с сохранением структуры,
связности, ссылочной целостности и статистики.

## Возможности
- Однопроходная потоковая обработка файлов до десятков ГБ (RAM ~126 МБ).
- Детерминированная псевдонимизация: одинаковый вход → одинаковый выход.
- Обезличивание всех полей с name, mRIDStr, ПДн, IP/портов, base64-вложений.
- Сохранение класса/напряжения (230 kV), перечислений CIM и графа связей.
- Мультиязычность через lang_<код>.json; валидатор качества.

## Запуск
pip install -r requirements.txt
python run.py input.xml output.xml --db mappings.db
python run.py --validate input.xml output.xml
